# TID chapters

Each week's lecture notes for **Technical Interaction Design** (ITU, Autumn 2026),
bundled into one PDF for reading offline or printing.

They are **generated**, from the markdown in
[itu-tid/itu-tid.github.io](https://github.com/itu-tid/itu-tid.github.io). If a chapter
and the notes ever disagree, the notes are the newer of the two — and the syllabus is what
decides which notes belong to which chapter.

Read them at **<https://itu-tid.github.io/lecture-notes-pdf/>**, or clone this repository.

---

This repository is rewritten, not appended to: every publish replaces its single commit,
so fourteen megabytes of rebuilt PDFs never pile up in the history. There is nothing here
worth keeping a history of — the history lives with the source.
